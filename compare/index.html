How to choose

  • Need everything in your account, and can wait? The ChatGPT and Claude data exports are official and free.
  • Need one long conversation now, as a text file you can edit or search? Look for a tool that exports the complete conversation to Markdown, and check the first and last messages in the file.
  • Need a formatted PDF or Word document? Several extensions above list those formats; check each listing for daily limits and plans.

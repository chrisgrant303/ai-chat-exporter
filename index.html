Summary

  • The Extension turns the AI chat you are viewing into a file that your browser downloads. Your conversations are processed only inside your browser. They are never sent to us, to our payment providers or to anyone else.
  • Free exports make no network request. On every supported site, ChatGPT included, the Extension reads the conversation from the page you are viewing. It sends no request of its own to the chat site. This holds even if you have an installation key from an earlier Unlock Pro or Restore purchase; with a key, only using Pro or visiting ExtensionPay's own pages can trigger a licence check (see Licence checks).
  • The only network contact is ExtensionPay (extensionpay.com), our payment provider, and only for Pro: when you use a Pro feature, unlock or restore Pro, or visit ExtensionPay's own pages (such as its checkout or account pages). Those requests carry an installation key, never your chats.
  • We run no server that receives data from the Extension. The Extension has no analytics, telemetry, advertising or tracking, and loads no remote code.

What the Extension accesses

  • The chat page you are viewing on a supported site (chatgpt.com, chat.openai.com, claude.ai, gemini.google.com, grok.com), only when you click an export button. The conversation is read and converted to a file in your browser.
  • Read from the page only: on every supported site, ChatGPT included, the Extension reads the conversation from the page you are viewing. It does not ask the chat site for the conversation, and it does not read your login session, cookies or tokens. To reach older messages, it scrolls the page, and the chat site's own page can then load them as it does when you scroll.
  • activeTab and scripting: when you open the Extension's popup on a supported chat tab that was open before the Extension was installed or updated, these let it load its own packaged exporter code into that one tab, so export works without reloading the page. When the Extension is installed or updated, it also tries to load the same code into supported chat tabs that are already open, but only into tabs that the browser lets it reach. If it cannot reach a tab, Export all can show a tip to reload it. They give no access to other tabs or sites.
  • "Export all open AI chats" (Pro): the Extension sends an export request to your open tabs; only tabs on the supported sites, where its exporter is running, respond and save a file. It does not read the addresses or content of other tabs.
  • storage: see "What is stored in your browser" below.
  • No new permissions: version 0.2.15 adds no new permissions and no new sites.
  • Welcome page: when you install the Extension for the first time, it opens its own welcome page in a new tab, one time. An update never opens it. The page is a file inside the Extension package. It runs no script and loads nothing from the internet. It does not need the tabs permission, and it stores nothing.

Pro purchases: what ExtensionPay and Stripe receive (Pro buyers only)

Pro is optional: a $4.99 one-time purchase, no subscription. It adds JSON export, an HTML download, PDF export (through your browser's print dialog) and exporting every open AI chat in one click. Like the free export, these files are created inside your browser. The HTML download is one file made on this device, as a local file, with no network use. Its styles are inside the file, and it loads nothing from the internet when you open it. Images in the chat appear in it as links. Pro is sold through ExtensionPay (extensionpay.com), a payment service for browser extensions, and paid through Stripe, which processes the card payment.

  • The first time you click Unlock Pro or Restore purchase: the Extension asks ExtensionPay to create an installation key, a random identifier for your copy of the Extension. This request contains no personal data, but like any web request it reveals your IP address and browser type to ExtensionPay. The Extension then opens ExtensionPay's checkout page in a new tab (or, for Restore purchase, ExtensionPay's login page in a small window).
  • On the checkout pages (ExtensionPay / Stripe Checkout): you type your email address and payment details directly into those web pages, not into the Extension. Stripe processes the payment details. ExtensionPay receives your email address and the purchase record (for example amount, date and paid status) and links them to your installation key. The Extension never sees your card details.
  • Licence checks: each time you use a Pro feature, and whenever you visit one of ExtensionPay's own pages (for example its checkout, payment-confirmation or account-management pages), the Extension sends ExtensionPay your installation key and nothing else from the Extension. While such a page is open, ExtensionPay's library can repeat this check about once per second for up to two minutes, without any click in the Extension. If you have never clicked Unlock Pro or Restore purchase, there is no key and nothing is sent. ExtensionPay answers with your licence status (whether and when you paid, and the email linked to the purchase). The Extension itself uses only the paid / not-paid answer. If ExtensionPay can't be reached, Pro keeps working offline for up to 7 days after your last successful check.
  • Opening the popup never contacts ExtensionPay. The popup shows Pro as unlocked or locked from the last result saved on your device. (Visiting ExtensionPay's own pages can, as described under Licence checks.)
  • ExtensionPay's pages: the Extension includes ExtensionPay's small script that runs only on extensionpay.com pages, so those pages can tell the Extension when a purchase is complete or your account has changed. That is what starts the repeated licence check described above.
  • Using Pro on another device or after reinstalling: click Restore purchase and log in on ExtensionPay's page with the email you paid with.
  • Never sent to ExtensionPay or Stripe: your conversations, chat titles, or the addresses of the pages you visit.
  • What we receive: as the seller, CCE Partners LLC can see the purchase record (your email, amount and date) in our ExtensionPay and Stripe accounts. We use it only for accounting, support and refunds, and keep it only as long as legally required.
  • Stripe's privacy policy: https://stripe.com/privacy. ExtensionPay describes how it handles user data in the FAQ on its website (https://extensionpay.com, "What about user privacy?"). For questions about it, contact us and we will help.

What is stored in your browser

  • The Extension stores no conversation content. Exported files go to your Downloads folder like any other download, and you control them.
  • In the Chrome version, everything the Extension stores is kept on this device only, in the browser's local extension storage (chrome.storage.local). One short-lived item (cce.preopen, below) is kept in its session storage (chrome.storage.session). In the Chrome version, nothing is written to the browser's sync storage. In the Firefox version, the payment library keeps its items in sync storage, and only after you allow the optional data collection permissions (see "Firefox version" below).
  • The Extension's own settings: whether Pro is unlocked (cce.license: paid yes/no and when it was last checked), a one-time "Pro unlocked" note (cce.proWelcome), and when the Pro hint was last shown or dismissed, and how many times you dismissed it (cce.nudge).
  • Two popup messages: the rating line, shown at most two times (cce.rate: a count of your successful exports, how many times the line was shown, and when it was shown or closed, when you clicked Rate or Send feedback, and when you chose Don't ask again) and the one-time pin tip (cce.tip: when the tip was shown or closed). These items contain only numbers and dates. They contain no chat content and are not sent anywhere.
  • The result of your latest Export all run (cce.bulk, Pro): when it ran, whether it is finished, and for each AI tab the site name, its tab and window position, whether the export worked and how many messages it saved. After an install or update, it can also keep how many open tabs need a reload. If the export of a tab fails, the result can also keep a short error message for that tab, up to 200 characters, that tells why it failed. It contains no chat content, no chat titles and no URLs, and it is not sent anywhere. The popup shows this result one time and then deletes it.
  • Tabs that were open when the Extension was installed or updated (cce.preopen): when this happened, whether it was an install or an update, how many tabs the Extension reached, for how many tabs the browser hid the address, and the browser's id numbers of the tabs it could not reach. It contains no chat content, no chat titles and no URLs, and it is not sent anywhere. It is kept in session storage (chrome.storage.session in the Chrome version, storage.session in the Firefox version), which the browser clears when it closes, or in local storage only if session storage is not available. Export all uses it for the reload tip. If the browser hid some tab addresses, Export all then deletes it. If not, the Extension keeps it until those tabs are reloaded or closed.
  • When the Extension first runs, the ExtensionPay library records the date it was installed (extensionpay_installed_at). In the Firefox version, the library records this date only after you allow the optional data collection permissions (see "Firefox version" below). This date is not sent anywhere.
  • Only if you click Unlock Pro or Restore purchase: the ExtensionPay library also stores the installation key (extensionpay_api_key) and your latest ExtensionPay status (extensionpay_user: paid status and date and the email you paid with).
  • Sync storage migration (Chrome version): Chrome version 0.2.2 and earlier kept the ExtensionPay items above in Chrome's sync storage. The Extension reads (never writes) its old sync data to migrate existing purchases: it copies those items into local storage, without any network request, so an existing purchase keeps working. Until an installation key is found there or this device has its own (for example, if you never clicked Unlock Pro or Restore purchase, or sync hasn't finished downloading yet), it repeats this read, on this device only, when the Extension is installed or updated and before a Pro feature, Unlock Pro or Restore purchase. After that, cce.syncMigrated records that the migration is done and sync storage is not read again. It never changes or removes anything in sync storage.
  • Uninstalling the Extension removes its local and session storage from your browser.

Firefox version

This section applies only to Unabridged on Firefox (addons.mozilla.org). Everything above applies to the Firefox version too, except where this section is different.

  • Unmodified ExtPay.js and sync storage: the Firefox version uses the unmodified ExtensionPay library (ExtPay.js 3.1.2). This library keeps its data in the browser's sync storage (storage.sync), not only on this device. It uses local storage on this device only if sync storage is not available. Firefox can copy sync storage to your other devices if you use Firefox Sync with add-on data syncing turned on. The items are the ExtensionPay items listed above. The library writes them only after you allow the optional data collection permissions (see "Consent first" below): first extensionpay_installed_at, and then, after you click Unlock Pro or Restore purchase, extensionpay_api_key and extensionpay_user. The Extension does not copy these ExtensionPay items to local storage. It reads them from sync storage, without any network request, when it is installed or updated and before a Pro feature, Unlock Pro or Restore purchase. This read can happen before you allow the optional permission below. If the items show a Pro purchase and this device has no saved Pro status yet, the Extension records in cce.license that Pro is paid. When it finds an installation key, it records in cce.syncMigrated that this check is done, and it does not read sync storage for this again. The Extension's own settings (cce.*, listed above) stay on this device only, in local storage (cce.preopen in session storage), as in the Chrome version. Uninstalling the Extension removes its storage from this browser. Your browser's sync service removes its copies according to its own rules.
  • Consent first: the Firefox version declares no required data collection. When you click Unlock Pro or Restore purchase, Firefox asks you to allow three optional data-collection categories: authentication information, financial and payment information and personally identifying information. Until you allow them, the ExtensionPay library does not start and stores nothing. The Extension makes no ExtensionPay request (no installation key, no checkout, no licence check), and Pro stays locked. If you remove that permission later (in about:addons), the Extension reloads and stops contacting ExtensionPay.
  • Licence checks: these are the same as in the Chrome version, described above. Opening the popup never contacts ExtensionPay. The Extension contacts ExtensionPay only when you use a Pro feature, unlock or restore Pro, or visit ExtensionPay's own pages. It never sends your chats. On ExtensionPay's own pages, if you already have an installation key, the unmodified library checks about once per second for up to 2 minutes, without any click in the Extension. On Firefox, none of this happens until you allow the optional permission. Pro keeps working offline for up to 7 days after your last successful check, as in the Chrome version.

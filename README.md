# Unabridged

Formerly AI Chat Exporter (Chrome) and Full Chat Exporter (Firefox).

Unabridged is a browser extension that exports a full AI chat, from the first message to the last, as one Markdown file. It works on ChatGPT, Claude, Gemini and Grok. The Markdown export is free and needs no account with us.

This repository hosts the Unabridged privacy policy. The extension code is not in this repository.

## Get Unabridged

- Chrome: [Unabridged: Export ChatGPT & Claude Chats to Markdown](https://chromewebstore.google.com/detail/bikcjbaffadliihjcbodbkddhlnpahhf)
- Firefox: [Unabridged: ChatGPT & Claude Chat to Markdown](https://addons.mozilla.org/firefox/addon/full-chat-exporter/)
- Product page: https://hichrisgrant.com/unabridged/

## Free and Pro

- Free: export the chat that you are viewing to Markdown.
- Pro: $4.99, one payment, no subscription. Pro adds JSON, HTML and PDF (through the browser print dialog) export, and export of all open AI chat tabs to Markdown.

## Privacy

Your chats are processed in your browser. They are never sent to us, to the payment provider or to anyone else. Read the full policy: https://chrisgrant303.github.io/ai-chat-exporter/

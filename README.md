# Unabridged

Unabridged is a browser extension that exports an AI chat to a Markdown file. It works on ChatGPT, Claude, Gemini and Grok.

**How to export a chat:** open the chat, click the Unabridged icon, then select **Export full chat → Markdown**. Your browser saves the file as a normal download and may ask you where to save it. Single-chat Markdown export is free and needs no account with us. Pro adds **Export → PDF (print)**, which opens your browser's print dialog, plus JSON and HTML downloads.

Formerly AI Chat Exporter (Chrome) and Full Chat Exporter (Firefox). This repository hosts the Unabridged privacy policy. The extension code is not in this repository.

## Steps

1. Install Unabridged from a store link above.
2. Open the chat on its site. Use your own account there.
3. Click the Unabridged icon. Check that the popup says **Detected:** and the name of the site.
4. Select **Export full chat → Markdown**. Keep the chat tab in front while it runs.
5. If the popup cannot reach the chat, reload the tab once, then export again.
6. Open the downloaded `.md` file. Check the first reply, a reply from the middle and the last reply.

## Check the file before you use it

The extension reads the chat from the page. A change to a site can affect the file. A saved file is not proof that every part was kept. Check the code and links that you need. On ChatGPT, closed web-source pills and collapsed code output can be left out; the file can then show `[web sources not included]` or `[code output not included]`. Keep separate copies of attachments and other files that you need.
